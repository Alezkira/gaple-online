# Gaple Online 🁘

Game Gaple (Domino) Multiplayer Online

## Fitur

- ✅ Multiplayer 4 pemain
- ✅ Bot otomatis jika kurang pemain
- ✅ Login/Register simpel
- ✅ Room system dengan kode unik
- ✅ Chat text
- ✅ ELO rating system
- ✅ Leaderboard global
- ✅ Responsive (HP & Laptop)

## Cara Main

1. Register akun
2. Buat room atau join room teman
3. Share kode room ke teman
4. Klik "Mulai Game" (host)
5. Main!

## Tech Stack

- **Backend:** Node.js + Express + Socket.io
- **Database:** SQLite (sql.js)
- **Frontend:** HTML + CSS + JavaScript
- **Hosting:** Railway.app

## Install Lokal

```bash
npm install
npm start
```

Buka http://localhost:3000

## Deploy

Deploy ke Railway.app (gratis)
